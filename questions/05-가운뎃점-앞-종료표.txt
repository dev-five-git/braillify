질문 05. 가운뎃점 앞의 로마자 종료표 (구현 반영, 확인 요청)

1. 규정 근거

  제29항은 국어 문장 안의 로마자 앞뒤에 로마자표와 로마자 종료표를 적도록 합니다.

  제33항은 통일영어점자와 한글 점자의 점형이 다른 문장 부호(, : ; ―)가 로마자와
  한글 사이에 나올 때 로마자 종료표를 적지 않도록 하고, [다만]에서 '. ? ! …'와
  '/ - ~'의 처리를 따로 정합니다. 가운뎃점은 두 목록 어디에도 없습니다.

  제50항은 가운뎃점을 앞뒤 말에 붙여 쓰도록 규정합니다.

2. 말뭉치의 처리 (두 판본 전수 대조)

  가운뎃점이 한 번만 나오는 문장을 두 판본에서 모두 세었습니다. 로마자 뒤의
  가운뎃점 앞에 종료표 ⠲을 적은 참조는 한 건도 없었습니다.

    로마자·한글  (PC·모바일)      2024: 234문장   2025: 283문장   종료표 없음 0 대 전부
    로마자·로마자 (PAHO·Pan)      2024: 101문장   2025:  87문장   종료표 없음 0 대 전부

  로마자·로마자에서는 가운뎃점 뒤에 로마자표 ⠴를 다시 적습니다 (87문장 전부).

    입력   PC·모바일
    참조   ⠴ ⠠⠠⠏⠉ ⠐⠆ ⠑⠥⠘⠣⠕⠂
    입력   DT·Digital
    참조   ⠴ ⠠⠠⠙⠞ ⠐⠆ ⠴ ⠠⠙⠊⠛⠊⠞⠁⠇

3. 현재 점역기의 처리 (구현 반영)

  가운뎃점 ⠐⠆는 통일영어점자에 대응 점형이 없으므로 제33항이 말하는 "점형이 다른
  문장 부호"에 속한다고 보아, 그 앞에서 종료표를 적지 않고 한글 점형으로 적도록
  고쳤습니다. 가운뎃점 뒤에 다시 로마자가 오면 로마자표를 다시 적습니다. 이로써 위
  유형의 문장은 모두 참조값과 일치합니다.

4. 여쭙는 내용

  가. 가운뎃점을 제33항의 "점형이 다른 문장 부호"로 보아 그 앞에서 로마자 종료표를
      적지 않는 위 처리가 맞습니까? 제33항의 괄호 안 목록(, : ; ―)은 예시입니까,
      한정 열거입니까?

  나. 로마자·로마자(DT·Digital) 사이의 가운뎃점 뒤에 로마자표를 다시 적는 것이
      맞습니까?

  다. 같은 표면형이 화학식이나 곱셈 기호로 쓰일 때에는 다르게 적어야 합니까?
      다르다면 묵자만으로 구분할 수 있습니까?
